# 选题生成与评分方法

## 一、证据优先级

1. 账号自己的已发布数据、评论需求和复盘；
2. 小红书公开笔记、活动、趋势和官方资料；
3. 有方法说明的行业数据与研究；
4. 搜索联想、问答、其他内容平台的共振；
5. 模型推断。

最终结果必须区分“事实”“推断”“创意”。只有模型推断时，将置信度标为低，并说明需要用发布测试验证。

## 二、关键词扩展

从用户输入扩展五类词：

- 对象词：头发、鞋袜、衣领、体态、房间、通勤等；
- 痛点词：廉价、邋遢、没精神、学生气、显呆、翻车、不合身；
- 场景词：开学、面试、入职、约会、见客户、见家长、出差；
- 限制词：低预算、5分钟、基础款、微胖、小个子、不会搭；
- 结果词：干净、利落、精神、可靠、成熟、自然、不用力过猛。

不要把搜索结果中的高频词直接当选题；先判断它是否适合账号、能否提供明确执行标准、是否已经重复。

## 三、可持续矩阵

候选由以下变量组合：

| 变量 | 示例 |
|---|---|
| 核心母题 | 干净感、利落感、精神状态、可靠感、生活秩序 |
| 人群阶段 | 大学生、实习生、职场新人、25岁以后、30岁以后 |
| 具体场景 | 上课、通勤、面试、约会、汇报、见客户、旅行、独居 |
| 限制条件 | 预算低、时间少、基础款、微胖、小个子、南北方气候 |
| 结果承诺 | 不显廉价、不显学生气、不翻车、看起来精神、自然得体 |
| 内容机制 | 自检、公式、避坑、对比、挑战、案例、测评、复盘 |
| 时间变量 | 季节、节日、开学、毕业、招聘季、换工作、平台趋势 |

先生成30个宽候选，再聚类、去重并筛到10个。默认同一对象或同一标题机制最多保留2个，防止清单内容垄断整批结果。

## 四、评分维度

所有维度使用0到10分：

- `account_fit` 20%：是否强化秩野Vibe定位；
- `audience_demand` 20%：是否存在明确、广泛或正在增长的需求；
- `evidence_strength` 15%：证据是否近期、直接、可追溯；
- `pain_specificity` 10%：是否指向具体场景与问题；
- `execution_value` 10%：用户是否能马上检查或行动；
- `click_potential` 10%：是否有清晰结果、反差或自查动机；
- `save_share` 10%：是否值得保存、转发或重复查阅；
- `series_value` 5%：是否能扩展为选题簇或栏目。

减分项同样为0到10分：

- `overlap_penalty`：与已发布、草稿或本轮候选重复；
- `saturation_penalty`：平台同质化严重且没有新角度；
- `risk_penalty`：证据不足、夸大承诺、专业风险或偏离定位。

脚本算法：基础加权分满分100；重复最多减12分，同质化最多减8分，风险最多减10分。

等级仅用于同轮排序：S≥80，A≥70，B≥60，C<60。若证据强度低于5分，即使总分较高也不能标为高置信度。

## 五、标题生成原则

标题优先回答：谁、在什么场景、遇到什么问题、能得到什么具体帮助。

推荐结构：

- 身份/场景 + 痛点 + 数字解决方案；
- 反常识纠偏 + 具体原因；
- 低预算/短时间限制 + 明确结果；
- 错误与正确对比；
- 可截图保存的公式或清单。

数字必须与正文一致。痛点词负责点击，正文必须给出判断标准。避免虚假紧迫、羞辱和无法验证的收益。

## 六、选题簇

不要一篇讲完就永久放弃一个母题。同一主题可以沿场景、预算、人群、季节、错误、护理、案例和实验继续扩展。例如白衬衫可产生合身判断、职场场景、微胖选择、面料差异、清洗护理、一衣多穿和粉丝案例。

重复主题允许，重复结论和重复角度不允许。
